# README 미디어 에셋

이 폴더의 이미지는 루트 `README.md`(한국어, 기본) / `README.en.md`(영어)에서 상대경로로 참조됩니다.

한국어 README(`README.md`, 기본)는 `.ko` 접미사 파일을, 영어 README(`README.en.md`)는 접미사 없는 파일을 씁니다.

| 파일 | 용도 | 상태 |
|------|------|------|
| `banner.png` | 상단 헤더 배너 (1600×440) | ✅ 있음 |
| `logo.png` | 앱 아이콘(노드 그래프) 사본 | ✅ 있음 |
| `search.png` / `search.ko.png` | 히어로 - 하이브리드 검색 결과 화면 (영/한) | ✅ 있음 |
| `map.gif` / `map.ko.gif` | 3D 시맨틱 지도(회전) (영/한) | ✅ 있음 |
| `sessions.png` / `sessions.ko.png` | 세션 브라우저 (영/한) | ✅ 있음 |
| `demo.gif` / 영상 | 데모 움짤/영상 (선택) | ⬜ 선택 |

> 위 스크린샷은 **가짜 데모 데이터**로 캡처한 것입니다(개인 대화 아님). 재생성/추가 캡처 방법은 아래.

## 히어로 이미지/스크린샷 넣는 법

1. 앱을 띄우고 원하는 화면을 캡처합니다(Windows: `Win+Shift+S`).
2. 파일을 이 폴더에 `hero.png`로 저장합니다.
3. README 상단의 `<!-- ... -->` 주석 블록을 찾아 **주석을 해제**하면 바로 표시됩니다.

> ⚠️ **프라이버시 주의(중요).** 이 저장소는 **공개(PUBLIC)** 입니다.
> 검색 결과·세션·3D 지도 화면에는 **실제 대화 내용/주제어**가 그대로 보일 수 있습니다.
> 공개 README에 올릴 스크린샷은 다음 중 하나를 권장합니다:
> - **설정·온보딩(모델 선택)** 화면 — 대화 내용이 없어 안전
> - **데모/샘플 데이터**로 앱을 띄워 캡처(빈 `ENGRAM_DATA_DIR`에 예시 세션만 색인)
> - 실제 데이터 화면을 쓰려면 **민감한 텍스트를 가리거나(blur)** 올려도 되는 내용인지 먼저 확인

## 데모 영상 넣는 법 (GitHub에서 재생되는 영상)

GitHub README에 **재생 가능한 영상**을 넣는 가장 확실한 방법:

1. 화면 녹화로 짧은 `.mp4`(또는 `.mov`, 100MB 이하)를 만듭니다. (Windows `Win+G` 게임바 녹화 등)
2. GitHub에서 **아무 이슈 작성 화면이나 이 저장소의 릴리스 편집 화면**을 열고, 영상 파일을 **본문에 드래그&드롭**합니다.
3. 업로드가 끝나면 `https://github.com/user-attachments/assets/...` 형태의 URL이 자동 생성됩니다. (이슈는 실제로 제출하지 않아도 됩니다.)
4. 그 URL을 README에 그대로 한 줄 붙여넣으면 **인라인 플레이어로 렌더링**됩니다:
   ```markdown
   https://github.com/user-attachments/assets/xxxxxxxx-xxxx-...
   ```

대안:
- **GIF 움짤** — `demo.gif`로 저장 후 `![데모](docs/assets/demo.gif)`. 간단하지만 용량이 크고 화질이 낮습니다.
- **YouTube 링크** — 썸네일 이미지에 링크를 걸어 사용: `[![데모](docs/assets/hero.png)](https://youtu.be/...)`.

영상도 위의 **프라이버시 주의**가 동일하게 적용됩니다 — 실제 대화가 화면에 보이지 않게 하세요.
